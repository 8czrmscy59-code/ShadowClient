# ShadowClient 1.20.1

A small client-side Fabric utility mod with a black/blue neon menu.

## Included
- Right Shift opens the menu.
- Toggleable HUD.
- Toggleable player coordinates.
- FPS display.
- Java 17 / Minecraft 1.20.1 / Fabric.

This starter project intentionally contains client-side HUD utilities rather than combat automation or multiplayer-disruptive features.

## Build
1. Install JDK 17.
2. Install Gradle 8.x.
3. Open this folder in a terminal.
4. Run `gradle build`.
5. The mod JAR will be in `build/libs/`.

## Install
Install Fabric Loader for Minecraft 1.20.1, then copy the built JAR into `.minecraft/mods`.
Fabric API for Minecraft 1.20.1 is also required.
